# Module 2 delivery: PostgreSQL initial data layer

## Scope
- Typed Prisma v7 schema with 12 core models, relations, foreign keys and unique/index constraints.
- Generated initial SQL migration in `packages/db/prisma/migrations/20261019000000_init_core/migration.sql`.
- Reusable Prisma client with Postgres driver adapter.
- Idempotent global permission catalog seed. **No seeded admin/password**.
- Real PostgreSQL integration smoke: relations, tenant-scoped unique keys, audit/outbox atomic rollback and session persistence.
- Cloud-only GitHub Actions using isolated PostgreSQL 16 with no dependency on personal hardware.

## Security rules
- Permission definitions are not permission grants. Module 3 implements organizational role grants and user provisioning.
- `Organization.id` foreign keys do not themselves enforce tenant isolation at query time; Module 3 must implement mandatory per-request org filters and record-level authorization. No application CRUD APIs are exposed here.
- Normalize login ID to lowercase before user creation in Module 3; PostgreSQL currently enforces case-sensitive org+login uniqueness.
- No provider secrets or client passwords stored in repository.
- Unrelated connected Neon project `Rovauto` is not modified.

## Infrastructure notes
- Neon project dedicated to DigiMarket must be selected/created as part of later cloud rollout, not borrowed from Rovauto.
- Production migrations require a separate direct Neon URL, runtime needs pooled URL.
- Migration generated by Prisma from committed schema and tested against GitHub-hosted PostgreSQL.
- No production DB connection, public signup, employee login or deployment created in Module 2.

## Acceptance criteria
- [ ] Prisma schema validates and Prisma client generates.

- [ ] Fresh migration deployment on PostgreSQL CI succeeds.
- [ ] Reapplying migration is idempotent.
- [ ] Role, user, team, session, founder, audit/outbox relations work.
- [ ] Tenant-scoped uniqueness and transaction rollback tested.
- [ ] Permission seed rerun does not duplicate grants/rows.
- [ ] Main branch CI green.
These gates are marked only after actual remote verification.
